# Basecamp Homepage UI – Front-End Styling Challenge

This project is part of a front-end styling technical test. The goal was to accurately replicate the Basecamp homepage design based on a reference PDF and a set of image assets provided in a `.zip` file.

## 🖼️ Challenge Description

- Recreate the layout and styling of the Basecamp homepage with close attention to visual details.
- All assets (images and design) were provided in the file: `2012_10_basecamp_homepage-test-6_v8.zip`.

## 🛠️ Technologies Used

- HTML5
- CSS3 (pure CSS, no frameworks)
- *(Optional: SCSS or JavaScript if used)*

## 📂 Project Structure

```
basecamp_homepage_ui/
├── assets/             # Provided image assets
├── css/
│   └── styles.css      # Custom styling
├── index.html          # Main HTML page
└── README.md
```

## 🔍 How to View the Project

Open the `index.html` file directly in your browser, or use a local development server (e.g. Live Server extension in VS Code).

## 📌 Additional Notes

- The design was replicated as close to pixel-perfect as possible based on the provided PDF.
- The code is clean, semantic, and organized for readability and maintainability.
